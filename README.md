# gpt-from-scratch

A small language model stack written from scratch in NumPy: an autograd engine, a GPT that grows from GPT-2 style to a modern Llama/DeepSeek-style block, and a set of measured experiments, all sized to run on a laptop CPU.

Work in progress. See the [milestones](https://github.com/kr1xh/gpt-from-scratch/milestones) for the plan.
